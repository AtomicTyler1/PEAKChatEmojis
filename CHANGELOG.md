# v0.1.2 - Update

- The emoji picker can now scroll, use the arrow keys and go beyond the top/bottom.
- The emoji picker now displays 9 instead of 8 emojis at once.
- Fixed an issue where duplicate names wouldn't be registered. Duplicates are now: "name~1" where the 1 can be any number.
   - This means everyone should have the EXACT same emoji packs if you have duplicates, otherwise others might see a different emoji than you do.
- If a message only consists of emojis, the message will now be bigger (size 40).
- Added a new emoji: `thumbs_up` - Which is just a cat with a thumbs up.
