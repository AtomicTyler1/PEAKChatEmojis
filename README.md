## What does PEAK Chat Emojis do?

Its an addon for [PeakTextChat](https://thunderstore.io/c/peak/p/borealityy/PeakTextChat/) that makes it so you can use emojis in your messages!

By default the mod comes with 16 emojis but other mods can add even more without touching any code!

Type `:emojiName:` for an emoji. Typing `:` will bring up an autocomplete panel, use the arrow keys and press tab to autofill in the emoji!
You can scroll past the 9 emoji previews by using your arrow keys, this means you do not need to memorize the names of the emojis, just scroll through them and find the one you want!

## Networking

The mod provides no additional networking however fully works with other people with the mod.
People with the mod will see the same emojis as you but only if you all have the same emoji packs downloaded.

- **Someone without the mod:** Hello :PEAK_Point:
- **Someone with the mod:** Hello {the image of Peak_Point}

This means the mod is fully client sided and won't break if someone is missing the mod.

## How to create an Emoji Pack

> If you don't plan to upload to Thunderstore, just create a folder in your BepInEx plugins folder called `Emojis` and place the images there.

1. Please create a basic [Package](https://wiki.thunderstore.io/mods/creating-a-package) for Thunderstore.
2. As a dependancy please add `AtomicStudio-PEAK_Chat_Emojis-0.1.0`.
3. In the package, create a folder called `plugins` and in that folder create `Emojis` (CAPITALISATION IS IMPORTANT).
4. Place your images into the folder, only `.png`, `.jpg` and `.jpeg` is currently supported.
5. Please have NO spaces in the file names, the name of the file is the name of the emoji.
